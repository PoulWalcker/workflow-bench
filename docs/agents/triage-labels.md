# Triage labels

The engineering skills speak in five canonical triage roles. This repository uses the role names
unchanged as the `Status:` value of a local ticket.

| Skill role | Ticket status | Meaning |
|---|---|---|
| `needs-triage` | `needs-triage` | Maintainer evaluation required |
| `needs-info` | `needs-info` | Waiting for more information |
| `ready-for-agent` | `ready-for-agent` | Fully specified and unblocked for an agent |
| `ready-for-human` | `ready-for-human` | Requires human implementation |
| `wontfix` | `wontfix` | Will not be implemented |

When a skill names a role, write the matching ticket status.
