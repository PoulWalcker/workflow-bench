# Отправить сообщение

Создай workflow, отправляющий заданный точный текст в чат с указанным chat_id
ровно один раз. Сохрани существующие чаты и сообщения. При неизвестном ID
ничего не отправляй и откажи с причиной not_found. Если ответ потерян, не повторяй
отправку автоматически: наблюдай эффект через разрешённое чтение либо сообщи unknown.

Это технический T1 API-only профиль. Проверяются адресат, текст, кратность,
сохранность и подтверждение эффекта защищённым журналом. Лимит чтения 100 сообщений
относится только к этому профилю; превышение возвращает limit_exceeded.
