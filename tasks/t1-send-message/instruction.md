# Отправить сообщение

Отправь заданный текст без изменений в указанный чат ровно один раз.
Сохрани существующие чаты и сообщения. Если чат отсутствует, ничего не отправляй
и объясни причину отказа. Если неизвестно, была ли отправка выполнена, проверь
результат доступным чтением либо честно сообщи о неопределённости.
Не отправляй сообщение повторно вслепую: дубликатов быть не должно.
