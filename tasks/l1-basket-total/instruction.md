# Basket total

A customer bought the following items:

| Item | Quantity | Unit price (cents) |
|---|---|---|
| apple | 3 | 45 |
| bread | 1 | 230 |
| milk | 2 | 119 |
| cheese | 1 | 575 |

Report the number of units bought and the amount to pay in cents.

Write the answer to `/work/output/answer.json` as one JSON object with exactly two integer
fields: `item_count` and `total_cents`. Only that file is assessed; a chat reply is not.
